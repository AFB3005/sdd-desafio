# sdd-desafio
Anthropic
Projeto desenvolvido como desafio prático de Spec Driven Development.

## Objetivo

Receber um arquivo JSON com despesas de um colaborador, aplicar as regras de reembolso e gerar um arquivo JSON com o resultado de cada despesa e os totais do período.
A interface esperada pelo desafio é:

```bash
<seu-comando> calcular --input despesas.json --output resultado.json
```

O comando definitivo será atualizado quando a implementação estiver pronta.

## Testes

Os testes automatizados são obrigatórios. O comando definitivo de testes será registrado aqui após a definição da stack no plan.md.

## Processo de desenvolvimento

O projeto segue esta ordem:

1. definir e revisar a spec;
2. criar o plano técnico;
3. dividir o trabalho em tasks;
4. implementar uma task por vez;
5. criar testes para cada comportamento;
6. registrar mudanças de requisito em DECISIONS.md;
7. exportar as sessões de trabalho para docs/sessions/;
8. escrever o relatório final com evidências do processo.
